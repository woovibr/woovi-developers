[Woovi Prompts](https://github.com/woovibr/woovi-prompts) is a public
repository of ready-made prompts for LLMs and agents (Claude Code, Cursor,
Copilot and similar) to integrate with the Woovi platform.

Each prompt is self-contained: assistant role, critical rule, technical
specification, implementation rules, code examples, expected API response and
output format. Pick the use case, copy the whole page and paste it into your AI
tool.
