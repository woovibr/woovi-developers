To create a Pix charge, use the API _endpoint_ `/api/v1/charge`.

You can find the documentation for this _endpoint_ [here](/api#tag/charge/POST/api/v1/charge).

The required fields to create a Pix charge are:

- **`value`**: The value of the Pix charge to be created, in cents.
- **`correlationID`**: A unique identifier for the Pix charge. [CorrelationID](../concepts/correlation-id)

## Example

Your request body will look like this example:

```json
{
  "value": 100,
  "correlationID": "c782e0ac-833d-4a89-9e73-9b60b2b41d3a"
}
```

After making the request, if everything went well, the request _status code_ will be `2xx` and the response `body` will contain the created charge.

### Code examples

<Tabs>
  <TabItem value="shell-curl" label="Shell + cURL" default>

```sh
  curl 'https://api.woovi.com/api/v1/charge' -X POST \
      -H "Accept: application/json" \
      -H "Content-Type: application/json" \
      -H "user-agent: node-fetch" \
      --data-binary '{"correlationID":"c782e0ac-833d-4a89-9e73-9b60b2b41d3a","value":1500}'
```

  </TabItem>
  <TabItem value="javascript" label="JavaScript + Fetch" default>

```js
fetch('https://api.woovi.com/api/v1/charge', {
  method: 'POST',
  body: JSON.stringify({
    value: 100,
    correlationID: 'c782e0ac-833d-4a89-9e73-9b60b2b41d3a',
  }),
  headers: {
    Authorization: 'AUTHORIZATION',
    'Content-Type': 'application/json',
  },
}).then((res) => res.json());
```
