To create a Pix charge with a due date, fine and interest, use the API's `/api/v1/charge` _endpoint_.

You can find the documentation for this _endpoint_ [here](/api#tag/charge/POST/api/v1/charge).

The required fields to create a Pix charge with a due date, fine and interest are the following:

- **`value`**: The amount, in cents, of the Pix charge to be created.
- **`correlationID`**: A unique identifier for the Pix charge. [CorrelationID](../concepts/correlation-id)
- **`type`**: The charge type. Specifically, the value `OVERDUE`.
- **`customer`**: An object representing the user who will receive the charge.

Inside **`customer`** you must send the CPF/CNPJ of the customer being charged.

If the customer is already registered in our database and has an address, this information is enough.

However, if the customer is not registered, or has no address registered, you must either register the customer with an address or send this information along with the request.

## Example

Your request body will look similar to this example:

```json
{
  "value": 100,
  "correlationID": "c782e0ac-833d-4a89-9e73-9b60b2b41d3a",
  "type": "OVERDUE",
  "customer": {
    "taxID": "607.681.970-74"
  }
}
```

After making the request, if everything went well, the request _status code_ will be `2xx` and the response `body` will contain the created charge.

### Code examples

<Tabs>
  <TabItem value="shell-curl" label="Shell + cURL" default>

```sh
  curl 'https://api.woovi.com/api/v1/charge' -X POST \
      -H "Accept: application/json" \
      -H "Content-Type: application/json" \
      -H "user-agent: node-fetch" \
      --data-binary '{"correlationID":"c782e0ac-833d-4a89-9e73-9b60b2b41d3a","value":1500, "type": "OVERDUE","customer": {"taxID": "607.681.970-74"}}'
```

  </TabItem>
  <TabItem value="javascript" label="JavaScript + Fetch" default>

```js
fetch('https://api.woovi.com/api/v1/charge', {
  method: 'POST',
  body: JSON.stringify({
    value: 100,
    correlationID: 'c782e0ac-833d-4a89-9e73-9b60b2b41d3a',
    type: 'OVERDUE',
    customer: {
      taxID: '607.681.970-74',
    },
  }),
  headers: {
    Authorization: 'AUTHORIZATION',
    'Content-Type': 'application/json',
  },
}).then((res) => res.json());
```
