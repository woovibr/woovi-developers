Once Loyalty Cashback is set up, follow the steps below to configure Loyalty Cashback directly in your settings.

- Go to the `Settings` tab in `Cashback Fidelidade` (Loyalty Cashback)
- Select enable, the cashback percentage to be generated and the minimum charge value to generate cashback

| Field                | Description                                                                                                                  |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| enable/disable       | enables the feature                                                                                                          |
| percentage           | percentage applied to the paid value of the charge                                                                           |
| minimum charge value | minimum value of a charge to generate cashback on the next purchase based on it. The platform minimum value is R$ 50.00      |
