## Pix QR Code

`Pix QR Code` webhooks send objects with the following fields in their payload:

- `pixQrCode`: Object with the QR Code details
- `pix`: Object with the Pix transaction details
- `company`: Company the transaction belongs to
- `account`: Details of the account the transaction belongs to
