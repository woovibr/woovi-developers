## Refund Payloads

Webhooks of type `Reembolso Recebido` (Refund received) send objects with the following fields in their payload:

- `event`: The type of event that occurred
- `charge`: The charge, if any, that the refund's original transaction belongs to
- `pixQrCode`: The QR Code, if any, that the refund's original transaction belongs to
- `pix`: Object with the Pix refund details
- `company`: Company the transaction belongs to
- `account`: Details of the account the transaction belongs to

You can tell whether the refund is **Partial** or **Full** from the `partial` field inside the `pix` object

Note that the `pix` object belongs to the refund itself, not to the original transaction.
