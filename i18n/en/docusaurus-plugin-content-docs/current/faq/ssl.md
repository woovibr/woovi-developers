## SSL/TLS version

Woovi's APIs use HTTPS following security best practices.

For your application or e-commerce to consume Woovi's APIs, it must support at least TLS 1.2; TLS 1.3 is recommended

## Where do I check which version my site is using?

To check your site's version, you can use the [SSL Labs](https://www.ssllabs.com/ssltest/analyze.html) site
