### What is a static Pix QRCode?

A static QR Code lets you receive multiple Pix payments with the same QR Code. It's ideal for LIVE streams and physical locations.

You can set this QR Code with a predefined payment amount or leave it open for the customer to enter the amount.

### How do I create a static QR Code?

1. In the menu, open the `QR Code` option

![Menu QRCode](/img/FAQ/QrCode-menu.png)

2. Click `Criar QR Code` (Create QR Code)

![Create QRCode](/img/FAQ/QrCode-btn.png)

3. Set the QR Code name

![Name QRCode](/img/FAQ/QrCode-name.png)

4. Choose whether the QR Code is static, always with the same amount, or printed, with its amount varying according to the Pix amount

![Static QRCode](/img/FAQ/QrCode-static.png)

5. Configure the amount settings

![Value QRCode](/img/FAQ/QrCode-value.png)

6. Optionally, add a comment to the QR Code, e.g. expiration date, sales campaign, etc.

![Value Comment](/img/FAQ/QrCode-comment.png)

After configuring it, click `Salvar` (Save).
