To get a subscription using the API, make a GET request to the _endpoint_ `/api/v1/subscriptions/<globalID>` using the subscription's `globalID`.

You can find the documentation for this _endpoint_ [here](/api#tag/subscription/GET/api/v1/subscriptions/{id}).

## Example

After making the request, if everything went well, the request _status code_ will be `2xx` and the response `body` will contain the subscription.

We will return the following example response:

```json
{
  "subscription": {
    "globalID": "UGF5bWVudFN1YnNjcmlwdGlvbjo2M2UzYjJiNzczZDNkOTNiY2RkMzI5OTM=",
    "value": 100,
    "customer": {
      "name": "Dan",
      "email": "email0@example.com",
      "phone": "5511999999999",
      "taxID": {
        "taxID": "31324227036",
        "type": "BR:CPF"
      }
    }
  },
  "dayGenerateCharge": 5
}
```
