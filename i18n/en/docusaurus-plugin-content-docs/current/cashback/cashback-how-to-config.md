Once cashback is set up, follow the steps below to configure it directly in your settings.

- Open the `Settings` tab in `Cashback`
- Select enable, the cashback percentage to be generated and the minimum charge amount that generates cashback

| Field                  | Description                                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------ |
| enable/disable         | enables the feature                                                                                                |
| percentage             | percentage applied to the amount paid on the charge                                                                |
| minimum charge amount  | minimum amount of a charge for it to generate cashback. The platform minimum is R$ 50.00                           |
