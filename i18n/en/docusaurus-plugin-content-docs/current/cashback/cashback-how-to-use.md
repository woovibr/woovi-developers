To enable Cashback for your company, follow the steps below:

## 1. Enable Cashback

- Open `Cashback` from the side menu
- ![cashback sidemenu](/img/cashback/cashback-sidemenu.png)

On your first access you will see the Cashback Tutorial.

![cashback tutorial](/img/cashback/cashback-tutorial.png)

> If you have already configured your cashback and want to review the settings, [learn more here](/docs/cashback/cashback-how-to-config)

### 1.1 Configure Cashback

- Select enable, the cashback percentage to be generated and the minimum charge value that generates cashback

| Field                | Description                                                         |
| -------------------- | ------------------------------------------------------------------- |
| enable/disable       | enables the feature                                                 |
| percentage           | percentage applied to the paid value of the charge                  |
| minimum charge value | minimum value a charge must have to generate cashback on it         |

After enabling the Cashback feature you will be redirected to the overview page.

![cashback overview](/img/cashback/cashback-overview.png)

## 2. Create a Charge with Cashback

Once cashback is enabled, the charge form will offer the option to enable it.

For the cashback option to be available, the charge must meet the minimum value set in the configuration.

![cashback charge form add](/img/cashback/cashback-charge-create-add-collapsible.png)

After filling in at least the minimum charge value, click to create the charge. You will be redirected to the charge details:
![cashback charge detail](/img/cashback/cashback-charge-detail.png)
