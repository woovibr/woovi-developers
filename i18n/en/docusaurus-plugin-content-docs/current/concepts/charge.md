## Charge

A Charge represents a payment request.

A Charge must have a value.

A Charge allows a payment to be automatically reconciled when it is received.

A Charge accepts only 1 payment.

A Charge has an expiration date.

Use cases: create a charge for an order, create a charge for a service, create a charge for a product.
