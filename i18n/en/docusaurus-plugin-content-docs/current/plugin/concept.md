## JavaScript Plugin

The Woovi JavaScript Plugin lets you create Pix charges and render Pix charges and Static QR Codes with just a few lines of code.

## Benefits of using the JavaScript Plugin

With the JavaScript Plugin, you don't need to worry about rendering Pix charges.

The JS Plugin renders the QR Code on desktop and the copy-and-paste code on mobile.

The JS Plugin also shows animations when the QR Code has been copied successfully.

The JS Plugin uses websockets, which ensures the payment is updated in real time, both on success and on expiration.

The JS Plugin also ensures the charge displays Cashback and Discount data correctly.

The JS Plugin renders a countdown timer to create payment urgency.

New Woovi design improvements are applied automatically to the JS Plugin.
