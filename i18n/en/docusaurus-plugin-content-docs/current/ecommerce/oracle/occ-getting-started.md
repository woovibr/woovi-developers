## Getting Started Guide

To start using Woovi, just follow these steps:

1. Sign up for a new account at [Sign up](https://woovi.com/register/?src=occ) or [Talk to Sales](https://woovi.com/join/?src=occ)
2. Create an API appID of type Oracle Commerce Cloud [here](/docs/apis/api-getting-started)
3. Follow the [integration guide](/docs/ecommerce/oracle/occ-integrating) to get started.
