A Woovi charge has a default expiration time of 1 month, but you can change this expiration time to fit your use case

In the Admin menu, go to `Settings` > `Pix`

![Woovi Expiracao](/img/flows/default_expiration.png)

Then change the charge expiration time to fit your use case

![Woovi Edit Expiracao](/img/flows/edit-default-expiration.png)
