# Woovi Developers

[https://developers.woovi.com](https://developers.woovi.com)

If you want to request a feature, open an issue on this [repo](https://github.com/woovibr/woovi-developers/issues).

## Running locally

```bash
pnpm install
pnpm start        # pt-BR (default locale)
pnpm start:en     # English
pnpm build        # production build
```
