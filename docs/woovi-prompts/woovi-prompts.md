[Woovi Prompts](https://github.com/woovibr/woovi-prompts) é um repositório
público com prompts prontos para usar com LLMs e agentes (como Claude Code,
Cursor, Copilot e similares) ao integrar com a plataforma Woovi.

Cada prompt é autocontido: papel do assistente, regra crítica, especificação
técnica, regras de implementação, exemplos de código, resposta esperada da API
e formato de saída. Escolha o caso de uso, copie a página inteira e cole na sua
ferramenta de IA.
