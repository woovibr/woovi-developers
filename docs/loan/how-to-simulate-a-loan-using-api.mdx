Para precificar um empréstimo antes de originar, use o _endpoint_
`POST /api/v1/loan/simulation`. Requer o escopo `LOAN_SIMULATION_POST`.

A simulação não cria nada para o tomador. Ela fica guardada até a
`expirationDate` e pode ser repetida à vontade.

## Campos do corpo

| Campo | Tipo | Obrigatório | Descrição |
| --- | --- | --- | --- |
| `taxID` | string | Sim | CPF ou CNPJ do tomador, com ou sem máscara. |
| `amount` | integer | Sim | Valor do empréstimo, em centavos, dentro dos limites do fundo que financia (por padrão de `10000` a `250000`). |
| `installmentNumber` | integer | Sim | Número de parcelas, de 1 ao máximo do fundo (por padrão 8). |
| `period` | string | Não | `WEEKLY` ou `MONTHLY`. Padrão `MONTHLY`. |
| `correlationID` | string | Não | Seu identificador. Repetir devolve a simulação guardada. |

### Exemplos em código

<Tabs>
  <TabItem value="shell-curl" label="Shell + cURL" default>

```sh
curl 'https://api.woovi.com/api/v1/loan/simulation' -X POST \
    -H "Content-Type: application/json" \
    -H "Authorization: {SEU_APP_ID}" \
    -d '{
      "taxID": "12345678909",
      "amount": 150000,
      "installmentNumber": 4,
      "period": "MONTHLY",
      "correlationID": "erp-sim-42"
    }'
```

  </TabItem>
  <TabItem value="javascript" label="JavaScript + Fetch" default>

```js
fetch('https://api.woovi.com/api/v1/loan/simulation', {
  method: 'POST',
  headers: {
    Authorization: '{SEU_APP_ID}',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    taxID: '12345678909',
    amount: 150000,
    installmentNumber: 4,
    period: 'MONTHLY',
    correlationID: 'erp-sim-42',
  }),
}).then((res) => res.json());
```

## Recusas

Uma simulação recusada **não** é erro HTTP: a resposta é `200` com
`status: "REFUSED"`, `simulationId: null` e o motivo em `refusalReason`.

```json
{
  "simulation": {
    "simulationId": null,
    "correlationID": "erp-sim-42",
    "status": "REFUSED",
    "refusalReason": "ALREADY_ACTIVE"
  }
}
```

| `refusalReason` | Significado |
| --- | --- |
| `ALREADY_ACTIVE` | O tomador já tem um empréstimo em aberto. |
| `TAXID_TYPE_NOT_ELIGIBLE` | O fundo não empresta para este tipo de documento (CPF ou CNPJ). |
| `CNPJ_REQUIRED` | O fundo só empresta para CNPJ. |
| `INSTALLMENTS_OUT_OF_RANGE` | O número de parcelas está fora do que o fundo permite. |
| `BELOW_MINIMUM` | O valor está abaixo do mínimo do fundo. |
| `ABOVE_CEILING` | O valor está acima do máximo do fundo. |
| `TICKET_CAP` | O valor está acima do máximo que o fundo empresta num empréstimo só. |
| `PERSON_CAP` | O tomador chegou ao máximo que o fundo empresta para uma mesma pessoa. |
| `PERSON_LIMIT` | O valor está acima do que o tomador pode pegar agora. |
| `NOT_ALLOWED` | O tomador não está elegível para crédito. |
| `SCREENING_REFUSED` | A análise do documento recusou. Um código só, de propósito: a API não diz se foi cadastro ou marcador de fraude. |

Os erros HTTP são:

| Status | `error` | Significado |
| --- | --- | --- |
| `400` | `INVALID_REQUEST` | Corpo inválido: valor ou número de parcelas fora dos limites do fundo, `period` desconhecido ou documento malformado. `message` diz qual campo. |
| `422` | `FUND_CLOSED` | Nenhum fundo ativo atende a sua empresa. |

O saldo do fundo não é checado na simulação, e sim na
[originação](./how-to-originate-a-loan-using-api#recusas): uma simulação aprovada
ainda pode ser recusada com `NO_FUNDS` ao contratar.
