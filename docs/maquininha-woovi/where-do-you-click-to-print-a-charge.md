Abra a cobrança na plataforma da Woovi e clique no botão **Imprimir na maquininha** (impressora conectada via USB). Para impressoras Bluetooth compatíveis, use o botão **Imprimir na maquininha via Bluetooth**.

Na primeira impressão, o navegador pede para você selecionar a impressora. Veja [Como imprimir uma cobrança?](./how-to-print-a-charge.md).
